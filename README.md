# Landing · Set Timeless de Dr. Grandel

Dominio: https://set-timeless.dr-grandel.es

Landing para consumidora final sobre el set Timeless de Dr. Grandel (Revitalizing Cream 50 ml + Eye & Lip 15 ml).
Sin referencias a tratamiento de cabina ni a centros.

- `index.html`: página completa (HTML + CSS + JS en un solo archivo)
- `img/`: imágenes y logotipos (wordmark y monograma en SVG)
- Llamada a la acción: «Habla con tu asesora personal» por WhatsApp

Asesoras: tabla `ASESORAS` al final de `index.html`. El enlace `?a=montse` dirige WhatsApp a esa asesora; sin parámetro se usa `DEFAULT`. El navegador recuerda la asesora y los enlaces para compartir la conservan.

Analítica: GoatCounter (sin cookies), panel drg-set-timeless.goatcounter.com. Eventos: wa-cabecera, wa-hero, wa-final, wa-flotante, compartir-whatsapp, compartir-copiar, compartir-otras, asesora-<código>, scroll-<sección>.

Publicación con GitHub Pages (rama `main`, carpeta raíz).
